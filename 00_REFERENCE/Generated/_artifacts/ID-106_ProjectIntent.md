## 1. Problem Statement & Background
Material and practical implementations for the course 'Redes neuronales generativas profundas: fundamentos y resolución de problemas' (2021). The repository consolidates hands-on notebooks, workshops, and code for training generative adversarial architectures (DCGAN, WGAN, CycleGAN, TimeGAN) for synthetic data and image generation.

---

## 2. Core Objectives
- Provide reproducible codebases and exercises for deep generative neural networks.
- Structure training pipelines for 2D synthetic imagery and time-series generation (TimeGAN).
- Curate practical workshops and reference materials conforming to the standardized 10-stage engineering pipeline.
